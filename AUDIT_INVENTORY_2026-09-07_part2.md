## Project Overview

Ovarian cancer is the fifth leading cause of cancer death in women. The standard first-line treatment is **platinum-based chemotherapy** (carboplatin or cisplatin), yet up to 25% of patients are intrinsically resistant and relapse within months.

This project builds a **binary classification pipeline** that predicts whether a patient will respond to platinum therapy — defined as overall survival beyond a fixed time threshold (12, 18, or 24 months) — using bulk RNA-seq gene expression profiles from the TCGA dataset.

**Clinical impact:** Early identification of resistant patients could redirect them to alternative or experimental therapies before completing an ineffective treatment cycle.

## Approach

### Label Engineering

Platinum response is defined as a **binary OS-based label** at each threshold:

```
response = 0  (Responder)      → OS ≥ threshold months
response = 1  (Non-responder)  → Died before threshold (event = 1, OS < threshold)
response = NaN (Ambiguous)     → Censored before threshold → excluded
```

Three thresholds are evaluated: **12m, 18m, 24m**.

### Feature Selection

- Top **500 most variable genes** are selected by training-set variance only (no leakage).
- Features are **z-score standardised** per gene (fit on train, applied to test).

### Models

All models use `class_weight='balanced'` to correct for label imbalance:

| Model | Regularisation | Notes |
|-------|---------------|-------|
| Logistic Regression (L2) | Ridge | Baseline linear model |
| Random Forest (300 trees) | Ensemble | Non-linear, feature importance |
| SVM (RBF kernel) | Soft-margin C=1 | Non-linear, robust to outliers |

### Evaluation

- **Primary metric:** ROC-AUC (insensitive to class imbalance)
- 5-fold stratified cross-validation on training set
- Hold-out test evaluation (20% stratified split)
- SHAP values for feature-level explainability
- Kaplan–Meier curves stratified by predicted risk group

git clone https://github.com/AaronC-bioinfo/ovarian-cancer-platinum-response.git
cd ovarian-cancer-platinum-response

python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

### 2. Download data

Follow the instructions in `data/README.md` to download the TCGA OV dataset from cBioPortal.

### 3. Configure paths

Copy the config template and fill in your local data path:

```bash
cp config/config.template.yaml config/config.yaml
```

Then edit `config/config.yaml` and set:

```yaml
data:
  data_dir: "path/to/your/ov_tcga_pan_can_atlas_2018"
```

Note: config/config.yaml is gitignored and never committed.
See config/config.template.yaml for all available options.

### 4. Run the full pipeline

```bash
python run.py
```

Optional arguments:

```bash
python run.py --data-dir /path/to/data         # override data directory
python run.py --thresholds 12 24               # run only 12m and 24m
python run.py --log-level DEBUG                # verbose logging
```

### 5. Run tests

```bash
pytest tests/ -v
```

### 6. Open the notebook

```bash
jupyter lab notebooks/analysis.ipynb
```

## Methods-Critique Ablation Study

`run_ablation_study.py` quantifies, with data rather than assertion, how much
two common evaluation mistakes inflate reported performance in genomic ML
papers:

1. **Feature-selection leakage** — computing gene-variance ranking on the
   full dataset before the train/test split, versus the correct train-only
   approach. Run across repeated random splits to report a distribution of
   the inflation, not a single anecdotal number.
2. **Single-split variance** — how much reported AUC swings purely from the
   luck of the random train/test split, motivating bootstrap confidence
   intervals and nested cross-validation over single hold-out reporting.

```bash
python run_ablation_study.py --n-repeats 30
```

Outputs:
- `outputs/results/ablation_leakage_summary.csv` — mean ± std AUC per
  model/threshold under leaky vs. correct conditions, plus the inflation delta
- `outputs/results/ablation_split_variance_summary.csv` — AUC range across
  repeated random splits
- `outputs/figures/fig8_leakage_ablation.png` — paired box plots visualising
  the inflation effect

This analysis requires no data beyond what's already configured for the main
pipeline, and is intended as the empirical backbone of a methods-critique
framing for publication — see the project's research roadmap for full context.

# Summary

`ovarian-cancer-platinum-response` is a modular, reproducible Python pipeline
for predicting platinum chemotherapy response in ovarian cancer patients using
bulk RNA-seq gene expression profiles from the TCGA Ovarian Serous
Cystadenocarcinoma cohort [@tcga2011]. The software trains and evaluates three
supervised classifiers — Logistic Regression, Random Forest, and Support Vector
Machine — across three survival thresholds (12, 18, and 24 months), and
provides evaluation tools including cross-validated ROC-AUC with bootstrap
confidence intervals, SHAP explainability [@lundberg2017], and Kaplan-Meier
survival stratification [@davidson2019].

Beyond the core prediction pipeline, the package includes a paired ablation
study that empirically quantifies AUC inflation from a widely documented but
poorly specified failure mode in genomic machine learning: computing feature
selection statistics on the full dataset before the train/test split. The key
contribution is the distinction between unsupervised variance-based filtering
(mean inflation: +0.01 AUC, non-significant across 30 repeated splits) and
supervised F-score-based selection (mean inflation: +0.22 AUC, up to +0.55 for
SVM, significant at p<0.0001 in 7 of 9 model/threshold combinations). A label
construct-validity investigation further examines whether the OS-threshold proxy
labels standard in this literature capture the clinical construct they are
assumed to represent.

# Statement of Need

Machine learning applied to cancer genomics regularly reports optimistic
performance, a problem attributed in part to feature selection leakage
[@vabalas2019; @teschendorff2019]. However, published guidance rarely
distinguishes between supervised selection methods — which directly use outcome
labels, creating a direct information pathway from test fold to training — and
unsupervised methods, which use only expression variance and create only an
indirect pathway. This distinction matters empirically: our ablation shows the
two conditions produce dramatically different inflation magnitudes (mean +0.22
vs. +0.01) on identical data and models. Existing genomic ML tools
[@zararsiz2017; @davis2007] do not include reproducible ablation frameworks
for quantifying this effect with paired statistical testing across repeated
splits.

A second unmet need is tooling to investigate label construct validity. TCGA-OV
lacks a direct platinum-response label; researchers use OS-threshold surrogates
without empirically verifying how well they capture the intended clinical
construct. The software's `label_investigation` module provides a reproducible
framework for this check, applicable to any TCGA cohort with partial clinical
response data alongside survival annotations.

# Architecture

The software is organised into eight source modules under `src/`: `data_loader`
(I/O), `preprocessing` (survival extraction, platinum-patient identification,
censoring-aware label assignment), `features` (train-only variance selection,
z-score scaling), `models` (classifier factories, CV utilities), `evaluation`
(metrics, results tables), `visualization` (seven figure types), `ablation`
(leakage conditions, bootstrap CIs, nested CV, paired significance tests), and
`label_investigation` (coverage, distribution, consistency, cross-tabulation,
exact binomial recall CIs).

All parameters are controlled via `config/config.yaml` (gitignored; a
committed template `config/config.template.yaml` is provided). Three CLI entry
points with `--help` (`run.py`, `run_ablation_study.py`,
`investigate_clinical_labels.py`) enable full pipeline reproducibility from a
single command.

# Testing

The package includes 52 unit tests across three modules. All tests use
synthetic data and pass without the TCGA dataset on disk, enabling CI/CD
integration. Three tests are regression tests for bugs that only surfaced on
real TCGA data (NaN values in RSEM matrices, mixed-type gene name indices) but
were not caught by earlier synthetic-data tests — documenting a real gap
between synthetic and real-data coverage.

# Results

On the platinum-treated TCGA-OV cohort (n=214/206/199 at 12/18/24m), Logistic
Regression achieved the highest test-set AUC at the 24-month endpoint
(mean ≈ 0.70 across 30 repeated correct splits). The ablation study confirmed
that unsupervised variance selection introduces negligible leakage while
supervised F-score selection inflates AUC by a mean of +0.22, with SVM
reaching AUC ≈ 1.00 under leaky conditions versus 0.45 under correct conditions
at the 12-month endpoint. The label investigation found that the OS-threshold
proxy had 0/5 recall (95% CI: [0.000, 0.522]) on the 7 clinically confirmed
Progressive Disease patients, consistent with the mechanistic argument that
overall survival and first-line treatment response are genuinely different
clinical constructs.

## 7. Leakage-safety inspection

### 7.1 Authoritative pipeline — train-only confirmed

**`src/features.py`** — variance filter, lines 43–44:

```python
variance = X_train.var(axis=0)
top_genes = variance.nlargest(top_n).index
```

Computed on `X_train` only; the same gene list is then applied to `X_test` (line 51). ✅

**`src/features.py`** — scaler, lines 71–73:

```python
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled  = scaler.transform(X_test)
```

`fit_transform` on train, `transform` only on test. ✅

**`src/pipeline.py`** lines 119–133 — correct ordering: `train_test_split` → `select_high_variance_genes(X_train, X_test)` → `scale_features(...)`. Selection and scaling both occur strictly after the split. ✅

**`src/ablation.py`** — the ablation is a deliberate, correctly-constructed contrast. Unsupervised arm, lines 109/113:

```python
# ── Condition A: LEAKY — variance computed on full X before split ──
leaky_genes   = _select_top_variance(X, top_n)
# ── Condition B: CORRECT — variance computed on X_train only ──
correct_genes = _select_top_variance(X_train, top_n)
```

Supervised arm, lines 221/225:

```python
# ── LEAKY: F-score computed on full X, y before splitting ──
leaky_genes   = _select_top_f_score(X, y_arr, top_n)
# ── CORRECT: F-score computed on training fold only ──
correct_genes = _select_top_f_score(X_train, y_train, top_n)
```

In both arms the scaler is re-fit per condition inside the loop on `Xtr` only (lines 120–122, 232–234). The leaky condition is leaky *by construction*, which is the point of the experiment. ✅

Its outputs (`cv_*`) are the ones used for all Finding 5 numbers verified in §2.

### 7.3 Verdict — with one caveat

**The authoritative pipeline is leakage-free with respect to the held-out test set, as claimed.** Variance filtering and standardisation are both computed train-only, after the split, in `features.py`, `pipeline.py`, and both arms of `ablation.py`. The reported headline AUCs are not inflated by test-set leakage.

**One caveat you should know about, and it is not the leak the paper is about.** In `src/pipeline.py`, `cross_validate_model` is called at line 156 on `X_train_sc` — a matrix whose gene selection and scaler were fit on the *entire* training set, including each inner CV validation fold:

```python
X_train_sc, X_test_sc, scaler = scale_features(X_train_red, X_test_red)   # line 133
...
cv = cross_validate_model(trained, X_train_sc, y_train, ...)              # line 156
```

So any **cross-validation** score reported out of `pipeline.py` carries mild optimistic bias from within-training-set information sharing. This does **not** affect the held-out test AUCs, and it does **not** affect the ablation results in §2 (which re-fit per condition per split), nor the Finding 5 CV numbers (which come from `phase2_03d`, where selection is inside the fold). It is a limitation worth one sentence in Methods if any `pipeline.py` CV number appears in the manuscript. If none does, ignore it.

A Software Pipeline for Platinum Response Classification in Ovarian Cancer: Methods Critique, Feature Selection Leakage, and Cross-Platform Validation Limits
Aaron Michael Anuroop Chintala
School of Systems Biology, George Mason University, Manassas, VA, USA
ORCID: 0009-0009-0062-6453
Software DOI (Zenodo): 10.5281/zenodo.20802753
GitHub: https://github.com/AaronC-bioinfo/ovarian-cancer-platinum-response
Submitted to F1000Research · 2026
Abstract
Background. Platinum-based chemotherapy is the standard first-line treatment for high-grade serous ovarian cancer (HGSOC), yet predicting patient response from tumour transcriptomics remains an unresolved clinical challenge. Machine-learning classifiers trained on RNA-sequencing data have been proposed as predictive tools, but methodological problems — including data leakage, surrogate label validity, and poor cross-platform generalisation — are frequently underreported.
Methods. We present an open-source Python software pipeline (seven modules, CLI entry points, YAML-driven configuration, 52 unit tests) for platinum-response classification using TCGA Ovarian Serous Cystadenocarcinoma (PanCancer Atlas 2018) RNA-seq data. We deploy three classifiers (logistic regression, random forest, SVM with RBF kernel) with two feature-selection strategies (supervised F-score and unsupervised variance) across three OS-derived binary thresholds (12, 18, and 24 months). We conduct (1) a 30-split repeated ablation study comparing feature-selection strategies, (2) a construct-validity investigation of OS-threshold proxy labels, and (3) external validation on GSE63885, an independent microarray cohort with direct clinical platinum-response labels.
Results. Three key findings emerge. First, supervised F-score feature selection inflates reported AUC by a mean of +0.22 (range +0.03 to +0.55; 7/9 model×threshold combinations p < 0.0001), while unsupervised variance selection yields negligible inflation (+0.01, largely non-significant). Second, the OS-threshold proxy labels used in training achieve zero recall (0/5; 95% CI: [0.000, 0.522]) on the seven confirmed Progressive Disease patients in the dataset, indicating a construct-validity failure: OS-threshold labels capture long-run mortality trajectory rather than first-line drug-specific response. Third, all classifiers generalise to chance-level on GSE63885 (AUC range 0.36–0.60), with post-ComBat inter-platform correlation r = −0.005, demonstrating that RNA-seq-trained classifiers do not transfer to Affymetrix microarray data even after batch correction.
Conclusions. Supervised feature selection and OS-derived surrogate labels together produce misleadingly optimistic performance estimates for platinum-response prediction. The software pipeline, ablation framework, and cross-platform evaluation tools are released openly to support reproducible methods auditing in genomic machine learning.
Keywords: ovarian cancer, platinum resistance, machine learning, feature selection, data leakage, label validity, cross-platform validation, RNA-seq, transcriptomics, TCGA
1. Introduction
High-grade serous ovarian cancer (HGSOC) is the most common and lethal histological subtype of epithelial ovarian cancer [2]. Patients typically present at advanced stage (FIGO III–IV) owing to the absence of early symptoms and reliable screening tools. Platinum-taxane combination chemotherapy remains the backbone of first-line treatment, and the degree of platinum sensitivity is a primary determinant of prognosis [3]: patients who relapse within six months of completing platinum therapy (platinum-resistant disease) [4] have substantially shorter overall survival than those with a longer platinum-free interval.
Predicting platinum response from molecular tumour profiles has attracted considerable interest in the genomics community. The availability of large, well-annotated datasets — particularly from The Cancer Genome Atlas (TCGA) — combined with accessible machine-learning libraries has enabled numerous studies employing RNA-sequencing-derived gene expression to train classifiers. However, several methodological issues are recurrently observed in this literature without adequate acknowledgement.
A first concern is data leakage from feature selection. When feature selection (e.g., identifying the top-k most informative genes) is performed on the full dataset before splitting into training and test sets, information about test-set sample labels is inadvertently incorporated into the feature set. The magnitude of this leakage varies by method: supervised filter methods that rank features by their association with the label (e.g., ANOVA F-score) are particularly prone to leakage, while unsupervised methods that rank features by variance independent of the label are theoretically immune. Despite this well-documented distinction, many published studies do not specify whether feature selection occurred inside or outside the cross-validation loop [7,8,9].
A second concern is the construct validity of surrogate labels. TCGA data for many cancer types lack granular treatment-response records. A common workaround is to define platinum response via overall survival (OS) thresholds: patients surviving beyond a given month cutoff are labelled 'responders' and those who do not are labelled 'non-responders'. This approach conflates overall mortality trajectory with first-line chemotherapy response — a patient may die from unrelated causes or after second-line therapies while having been an excellent platinum responder. The degree to which OS-threshold labels agree with directly measured platinum response is rarely validated.
A third concern is cross-platform generalisation. RNA-seq RSEM quantification (TCGA) and Affymetrix microarray RMA signal (GEO datasets) have fundamentally different distributional properties. Standard batch-correction approaches such as ComBat were designed for within-modality batch effects and may not adequately bridge the gap between RNA-seq and microarray platforms. Classifiers trained on RNA-seq that are then evaluated on microarray validation cohorts without explicit quantification of inter-platform alignment may provide false confidence in generalisability.
To address these concerns transparently, we built an open-source software pipeline for platinum-response classification and then conducted three structured analytical investigations: an ablation study quantifying leakage from feature selection, a clinical-label validation study, and external validation on an independent microarray cohort. We report all findings — including the negative result that classifiers fail to generalise — to provide the research community with a reproducible baseline and methodological framework.
2. Methods
2.1 Dataset
Gene expression data were obtained from the TCGA Ovarian Serous Cystadenocarcinoma (OV) cohort, PanCancer Atlas 2018, accessed via cBioPortal. The primary expression file used was data_mrna_seq_v2_rsem.txt, containing raw RSEM-normalised RNA-seq counts for protein-coding genes. The clinical annotation file data_clinical_patient.txt supplied overall survival (OS) in months and OS status for each patient.
Platinum-treated patients were identified using data_timeline_treatment.txt. Entries with AGENT field values corresponding to carboplatin or cisplatin were retained, and only patients receiving at least one platinum-containing regimen were included in the analytic cohort. This filtering step is not present in earlier versions of our Methods text and is corrected here for transparency. After histological and quality-control filtering, the cohort comprised 214 patients at the 12-month threshold, 206 at 18 months, and 199 at 24 months.
OS-threshold binary labels were defined as follows: patients with OS ≥ t months were labelled 'long survival' (proxy responder, label = 0); patients with OS < t months or who died before t months were labelled 'short survival' (proxy non-responder, label = 1), for t ∈ {12, 18, 24}.
A secondary clinical variable, PRIMARY_THERAPY_OUTCOME_SUCCESS, was available for a subset of patients (11% non-null coverage in the platinum cohort; n = 7 Progressive Disease cases confirmed). This variable records the attending oncologist's assessment of first-line therapy response and was used as a ground-truth reference for construct-validity analysis only; it was not used as a training label.
2.2 Software Pipeline
The pipeline is implemented in Python 3.12 as a modular package with the following source modules:
data_loader: reads TCGA expression and clinical files, parses RSEM data, filters platinum-treated patients
preprocessing: extracts survival data, identifies platinum-treated patients, assigns OS-threshold binary labels, cleans and aligns the expression matrix
features: implements unsupervised variance-based gene selection (select_high_variance_genes) and StandardScaler z-score normalisation (scale_features, fit on training set only); supervised F-score selection is implemented in ablation.py for the leakage ablation study
models: wraps scikit-learn logistic regression, random forest, and SVM (RBF kernel) classifiers
evaluation: computes AUC with 95% CIs via DeLong method and permutation testing
ablation: conducts the leakage ablation study across 30 repeated random splits
label_investigation: cross-tabulates OS-threshold labels against PRIMARY_THERAPY_OUTCOME_SUCCESS
CLI entry points (run.py, run_ablation_study.py, investigate_clinical_labels.py) allow full pipeline execution without editing source code. All parameters are specified via a YAML configuration file with no hardcoded values. The package includes 52 unit tests spanning preprocessing, ablation, and label-investigation modules; all tests pass without the TCGA data on disk by using synthetic fixtures. The software is available at https://github.com/AaronC-bioinfo/ovarian-cancer-platinum-response (DOI: 10.5281/zenodo.20802753).
2.3 Classification Experiment
Three classifiers were trained and evaluated: logistic regression (L2 regularisation, C = 1.0), random forest (100 estimators, max_features = 'sqrt'), and SVM with RBF kernel (C = 1.0, gamma = 'scale'). Feature sets were reduced to 500 genes prior to model training. All classifiers were evaluated via stratified 80/20 train–test splits repeated 30 times with different random seeds. AUC was computed on the held-out test set in each split and averaged across repeats.
2.4 Feature Selection Leakage Ablation Study
To quantify the magnitude of leakage introduced by supervised feature selection, we implemented a paired ablation design. For each of the 30 repeated splits, we computed AUC under two conditions:
Leaky: F-score feature selection performed on the full dataset (training + test combined) before splitting. This mirrors the common practice of selecting features once, before cross-validation.
Clean: F-score feature selection performed on the training set only, after splitting. Test-set samples are excluded from feature scoring.
A paired Wilcoxon signed-rank test was used to assess statistical significance of the difference in AUC between leaky and clean conditions across the 30 splits. The same ablation was conducted for unsupervised variance-based selection to provide a negative control. Because variance is computed independently of labels, it is not subject to leakage.
2.5 Label Construct Validity Investigation
To assess whether OS-threshold proxy labels correspond to direct clinical platinum response assessments, we cross-tabulated the 12-month OS-threshold label with PRIMARY_THERAPY_OUTCOME_SUCCESS for the subset of patients where both were available (n = 7 confirmed Progressive Disease patients). Sensitivity, specificity, and 95% confidence intervals (Clopper-Pearson exact method) were computed for the OS-threshold label's ability to identify confirmed Progressive Disease patients.
2.6 External Validation (GSE63885)
External validation was performed on GSE63885 (Lisowska et al., 2014), a publicly available Affymetrix HG U133 Plus 2.0 (GPL570) microarray cohort of 101 samples. After filtering to serous and undifferentiated histology, 80 samples were retained. Two label sets were used:
Clinical label: CR/PR (complete or partial response) = 0 vs. P/SD (progressive or stable disease) = 1 (n = 74 labeled; 64 responders, 10 non-responders)
DFS label: platinum-sensitive = 0 vs. platinum-resistant = 1 derived from disease-free survival threshold (n = 75 labeled; 40 sensitive, 34 resistant)
Preprocessing of GSE63885 followed four steps implemented in R (version 4.6.0) and Python 3.12. First, probe-to-gene mapping was performed using the hgu133plus2.db Bioconductor annotation package; for genes with multiple probes, the probe with the highest mean expression across samples was retained, yielding 21,355 genes. Second, the TCGA and GEO gene sets were intersected, retaining 15,477 genes in common. Third, gene-level z-score normalisation was applied within each dataset independently. Fourth, ComBat batch correction (R sva package) was applied treating platform (TCGA RNA-seq vs. GSE63885 microarray) as the batch variable. The inter-platform Pearson correlation of gene-level mean expression (computed post-ComBat) was used as a diagnostic of alignment quality.
Classifiers trained on the full TCGA platinum cohort were applied to the harmonised GSE63885 expression matrix, and AUC was computed for each model×threshold combination.

3.3 Label Construct Validity (Finding 2)
Of the 214 patients in the 12-month platinum cohort, PRIMARY_THERAPY_OUTCOME_SUCCESS was non-null for 24 patients (11.2%). Among these, seven were confirmed Progressive Disease. The 12-month OS-threshold proxy label was assessed for its ability to identify these seven confirmed non-responders.
The OS-threshold label showed zero recall on confirmed Progressive Disease patients: 0 of 5 (among the subset where both fields were non-null; 95% CI: [0.000, 0.522]). All five confirmed Progressive Disease patients were classified as 'long survival' (label = 0) by the OS-threshold definition, meaning the proxy label actively contradicted the clinical assessment in every case where both were available.
This finding reflects a genuine construct-validity failure rather than a measurement error. OS-threshold labels capture long-run mortality trajectory — a patient may be a confirmed non-responder to platinum yet survive longer than the threshold due to second-line therapy, supportive care, or unrelated health factors. Primary therapy outcome, in contrast, captures the attending oncologist's assessment specifically of first-line platinum response. These are genuinely different clinical constructs that are not interchangeable as binary labels for training.
Secondary covariates assessed for potential inclusion in future Cox modelling showed mixed coverage: GRADE had 82% coverage but 83% of patients were Grade 3, leaving insufficient variance for covariate adjustment. TMB (tumour mutation burden) had 91% coverage and ANEUPLOIDY_SCORE had 96% coverage; both are viable candidates for future analysis.

4. Discussion
The three findings reported here have distinct but complementary implications for genomic machine learning applied to cancer treatment response.
4.1 Feature Selection Leakage is Quantitatively Large
The +0.22 mean AUC inflation from supervised feature selection is not a subtle or theoretical concern. At the extreme (SVM, 12 months), a classifier with true discriminative power near chance (AUC 0.45) could be reported as near-perfect (AUC ~1.00) if features are selected on the full dataset. Researchers comparing classifiers in the literature are unlikely to be comparing methods on equal footing unless the feature-selection order is standardised and reported. The finding that unsupervised variance selection produces negligible inflation provides a practical recommendation: variance-based pre-filtering, applied before the train–test split, is a leakage-free alternative for dimensionality reduction and does not require labels.
Notably, the magnitude of leakage is threshold-dependent: the 12-month threshold produced the largest inflations, likely because the class balance is most extreme at this cutoff (few patients survive less than 12 months in HGSOC), making label-correlated genes easiest to identify spuriously on small test sets.
4.2 OS-Threshold Labels are Inappropriate for Drug-Response Classification
The zero-recall finding for OS-threshold labels on confirmed Progressive Disease patients is alarming as a construct-validity result. The small n (5 patients with both fields non-null) prevents a definitive statistical statement, but the direction is unambiguous: every confirmed non-responder in the available data was misclassified as a long-survivor by the OS threshold. This is consistent with the known clinical biology of HGSOC: patients with progressive disease on platinum can be transitioned to second-line taxane, bevacizumab, or PARP inhibitor therapy [5,6], extending survival substantially beyond any fixed month threshold.
The implication for future work is clear: classifiers targeting first-line platinum response should not be trained on OS-threshold labels unless independently validated against direct treatment-response annotations. TCGA's PRIMARY_THERAPY_OUTCOME_SUCCESS field, despite its sparse coverage (11% in this cohort), is a more appropriate — if underpowered — training label. Richer data sources such as PTRC-HGSOC, which include longitudinal treatment records and response assessments, are preferable but require data-access approval.
4.3 RNA-seq Classifiers Do Not Transfer to Microarray Cohorts via ComBat
The external validation failure, mechanistically explained by the r = −0.005 post-ComBat inter-platform correlation, carries a direct practical warning: cross-platform validation using ComBat is not a reliable method for assessing generalisation between RNA-seq and microarray datasets. The distributional differences between RSEM and RMA are not addressable by an additive batch-effect model. Future validation studies that cross platforms should employ reference-based methods, quantile normalisation against a matched reference, or retrain classifiers in the target platform's distributional space.
The finding that feature selection was not the bottleneck (variance ratio = 1.00×) is informative: this rules out the hypothesis that TCGA's most variable genes are simply less variable in the microarray space. The failure is a platform-harmonisation problem, not a feature-quality problem.
Figure 3. External validation AUC on the GSE63885 microarray cohort. Heatmaps show AUC for each model × OS threshold combination under clinical response labels (left; CR/PR vs P/SD, n = 74) and DFS-derived labels (right; sensitive vs resistant, n = 74). All values cluster near chance level (0.5), consistent with the post-ComBat inter-platform Pearson r = −0.005.
4.4 Relationship Between Findings
The three findings are complementary. Finding 1 shows that the pipeline's training-phase performance estimates cannot be trusted at face value without specifying feature-selection order. Finding 2 shows that even with clean feature selection, the training labels are poor proxies for the clinical construct of interest. Finding 3 shows that, even granting both the performance estimates and the labels, the classifiers do not generalise across platforms. Together they constitute a cascading audit: each finding would independently motivate a re-evaluation of the literature; together they suggest that published platinum-response AUC values should be interpreted with substantial caution.
4.5 Limitations
Several limitations should be acknowledged. The confirmed Progressive Disease sample is very small (n = 7; n = 5 with both fields non-null), limiting the power of the construct-validity analysis. The external validation cohort (GSE63885) has a severely imbalanced clinical label set and would benefit from additional validation on cohorts such as GSE32062 or GSE26712. The binary OS-threshold framework for training labels is unlikely to be superseded by simple covariate additions; a fundamentally different label strategy (e.g., direct response annotation or PFI-based platinum-free interval) is warranted. Finally, we did not explore deep-learning architectures or graph-based methods; the findings here are specific to the three shallow classifiers evaluated.
5. Conclusion
We present an open-source, modular Python pipeline for platinum-response classification in HGSOC and report three methodologically important findings. Supervised feature selection inflates reported AUC by a mean of +0.22 (up to +0.55) due to label leakage into the feature space; unsupervised variance selection is the appropriate leakage-free alternative. OS-threshold proxy labels fail to identify confirmed Progressive Disease patients (0/5 recall), indicating a construct-validity gap between mortality trajectory and first-line drug-response labels. External validation on an independent microarray cohort yields near-chance AUC (0.36–0.60) for all classifiers, with inter-platform correlation r = −0.005 after ComBat, confirming that RNA-seq-trained classifiers do not generalise across platforms by standard batch-correction methods.
These findings do not invalidate the use of machine learning in platinum-response research; rather, they define the conditions under which reported performance is meaningful. The software pipeline, ablation tools, and validation scripts are publicly available and designed to be reusable on future datasets.

Abstract

Author Summary
Doctors currently have limited ways to predict, before treatment begins, which ovarian cancer patients will respond well to platinum-based chemotherapy — the standard first-line treatment for this disease. Many research groups have tried to build computer models that predict this from tumor genetics, often reporting very high accuracy. We found that much of this apparent accuracy is an illusion caused by a subtle but common technical mistake: selecting the most informative genes using the full dataset before, rather than after, splitting the data into training and testing sets. When we corrected this mistake, model accuracy dropped substantially — and we found the same problem when we repeated the analysis in two other cancer types, suggesting it is a widespread issue in this field rather than one specific to ovarian cancer. We also found that the labels commonly used to indicate "drug response" in this public dataset often reflect how long a patient survived overall, rather than whether the tumor specifically responded to the drug — two related but genuinely different things. Introduction
High-grade serous ovarian cancer (HGSOC) accounts for the majority of ovarian cancer deaths and is typically diagnosed at an advanced stage, when standard treatment consists of cytoreductive surgery combined with platinum-based chemotherapy [23]. While most patients initially respond, a large fraction ultimately develop platinum-resistant disease, and there is currently no validated, pre-treatment genomic biomarker in routine clinical use to identify which patients are likely to fail platinum therapy. This gap has motivated a substantial body of work applying machine learning (ML) to The Cancer Genome Atlas ovarian cancer (TCGA-OV) cohort and related public datasets, with numerous studies reporting classifiers that achieve high discriminative accuracy for platinum response from gene expression, mutation, or copy-number data [1–5,10].
However, genomic machine learning is well documented to be susceptible to methodological pitfalls that can substantially inflate apparent performance. Data leakage introduced when feature selection is performed on the full dataset prior to train/test splitting is a recognized but inconsistently addressed problem in high-dimensional biomedical data analysis [13,14]. Independently, it has been shown that even gene signatures selected at random — with no relationship to the biology of interest — are frequently found to be significantly associated with clinical outcome in cancer cohorts, a phenomenon attributable to the general prognostic value of proliferation- and stroma-related transcriptional programs rather than any specific biological signal [15]. Beyond feature selection, the clinical labels used to define "platinum response" ML in this literature are frequently imperfect proxies — most commonly an overall-survival threshold — rather than directly annotated drug-response outcomes, raising a construct-validity concern that is separate from, but compounds, any modeling-stage leakage.
In this study we directly and systematically quantify these methodological pitfalls in the specific context of TCGA-OV platinum response prediction, and then use a leakage-free, label-honest framework to ask what can still be learned, reliably, from this dataset about the biology and genomics of platinum response. Specifically, we: (1) quantify the magnitude of feature-selection leakage in a representative classification pipeline and test whether the same pattern generalizes to two additional TCGA cancer types; (2) evaluate the construct validity of the overall-survival-threshold label commonly used in this literature against a small set of directly annotated response outcomes; (3) test whether classifiers trained on TCGA RNA-seq data generalize to an independent microarray validation cohort, and characterize the mechanistic basis of any failure to do so; (4) fit a Cox proportional hazards survival model using established genomic covariates and confirm its properties are robust to tumor cellularity; (5) use cross-validated SHAP-based feature importance and pathway enrichment to identify which biological themes among the model's most important genes are robust, and which are not; (6) test whether BRCA1/2 mutation status, as a marker of homologous recombination deficiency, improves the survival model; and (7) rigorously test, using nested cross-validation, whether adding gene expression data as covariates improves prognostic power beyond these established genomic markers.
We note explicitly that our methodological critique is directed at studies that claim, implicitly or explicitly, generalizable predictive performance for platinum response. Many analyses of NGS datasets are conducted with a descriptive or exploratory goal — characterizing associations within a dataset rather than building a model intended to generalize to new patients — for which the statistical standards we apply here are correspondingly less critical. Our findings should be read as pertaining specifically to the predictive-modeling use case.
Materials and Methods
Dataset and cohort definition
All analyses used the TCGA Ovarian Serous Cystadenocarcinoma PanCancer Atlas 2018 dataset, obtained via cBioPortal [24,25]. Gene expression values were taken from the raw RSEM-normalized file (data_mrna_seq_v2_rsem.txt); the pre-z-scored expression release distributed alongside this dataset was not used for model training, since standardization was instead fit on training data only and applied post-split, to avoid leakage of test-set statistics into the training distribution. Platinum-treated patients were identified from data_timeline_treatment.txt via the AGENT field, matching carboplatin- and cisplatin-containing regimens. This yielded a complete-case cohort of n=432 patients with treatment, survival, tumor mutational burden (TMB), and Aneuploidy Score data for Cox modeling, and cohorts of 214, 206, and 199 patients with adequate follow-up for binary classification at 12-, 18-, and 24-month response thresholds, respectively.
Feature-selection leakage ablation
To quantify feature-selection leakage, we compared model performance under two feature-selection conditions: (i) unsupervised variance-based selection of the top 500 genes, computed independently within each training fold, and (ii) supervised F-score (ANOVA) selection of the top 500 genes, computed on the full dataset prior to splitting — a leakage-inducing but not uncommon practice in the applied literature. Logistic regression, random forest, and support vector machine (RBF kernel) classifiers were evaluated under both conditions across 30 repeated random splits per model and time threshold. To test whether this pattern was specific to ovarian cancer, the identical ablation pipeline was applied, without modification, to two additional TCGA PanCancer Atlas 2018 cohorts: lung adenocarcinoma (LUAD) and colorectal adenocarcinoma (COADREAD, platinum defined as oxaliplatin-containing FOLFOX regimens).
Label construct validity
We compared the directly annotated clinical variable PRIMARY_THERAPY_OUTCOME_SUCCESS against an overall-survival (OS) threshold proxy label (alive/censored beyond threshold = responder) at each of the three time thresholds. Proxy-label recall was evaluated specifically against the subset of patients with a confirmed Progressive Disease annotation, the clearest available ground truth for non-response.

Independent validation used GSE63885 [11], a microarray cohort (Affymetrix HG-U133 Plus 2.0, GPL570) of 101 ovarian cancer patients with clinical response (CR/PR vs. SD/PD) and disease-free-survival(DFS)-threshold labels. Probes were mapped to gene symbols, and platform harmonization with TCGA RNA-seq was performed via ComBat batch correction (sva package [17]) treating platform as the batch variable. Classifiers trained on TCGA data were applied directly to the harmonized GEO expression matrix. To distinguish feature-selection from platform-level explanations for any validation failure, we additionally compared the variance of TCGA's selected genes to the variance of all genes within the GEO dataset itself, and computed the post-ComBat Pearson correlation between platform-matched samples. Cox proportional hazards modeling
Survival was modeled using coxph() (R survival package) as Surv(OS_MONTHS, OS_STATUS) ~ log1p(TMB_NONSYNONYMOUS) + ANEUPLOIDY_SCORE, using the complete-case n=432 cohort. The proportional hazards (PH) assumption was tested via Schoenfeld residuals. Patients were stratified into risk tertiles using the model's linear predictor, and separation was assessed via Kaplan–Meier curves and the log-rank test.

Tumor purity was estimated using the ESTIMATE algorithm [28] on the 235-patient subset of the platinum-treated cohort with available RNA-seq data. Purity was added as an additional Cox covariate to test for confounding of the baseline model. To test whether purity confounded downstream feature-importance results, gene expression was residualized against ESTIMATE-derived tumor purity via ordinary least squares prior to re-computing the variance-based gene filter and re-running pathway enrichment (below), using an otherwise identical methodology to the uncorrected analysis.

Random forest classifiers (300 trees, class_weight="balanced") were trained on the top 500 variance-filtered genes, computed on training data only and independently for each of the three time thresholds. All three methods were therefore recomputed under a fair, cross-validated design — repeated stratified k-fold cross-validation (5 folds × 5 repeats = 25 evaluations), with all three methods computed identically within each fold and the variance-based gene filter recomputed on training data only, per fold and per threshold. Gene-importance rankings were averaged across the 18- and 24-month threshold models; the 12-month threshold model was excluded from this averaging after confirming, across 25 cross-validation folds, that its discriminative performance was chronically unstable (mean AUC 0.475, SD 0.198, range 0.075–0.976) and consistent with near-chance performance, a consequence of its small number of events (n=11). Pathway enrichment of the resulting gene-importance rankings was performed via the Enrichr API against the KEGG_2021_Human, Reactome_2022, GO_Biological_Process_2023, and MSigDB_Hallmark_2020 libraries, at gene-list sizes of 50, 100, 200, and 500, using Benjamini–Hochberg adjusted p-values. A gene-list size of 200 was adopted as the standard reporting cutoff, being the smallest list size at which all enrichment themes discussed below reached statistical significance under the SHAP-based ranking.
Homologous recombination deficiency and BRCA1/2 status
Somatic BRCA1/2 mutation status was extracted from the TCGA-OV mutation annotation file (MAF), retaining non-silent variants. This was added as an additional Cox covariate (BRCA_any_mutated) to the baseline survival model. The top-500 variance-filtered gene list was separately cross-referenced against a curated panel of homologous-recombination-repair (HRR) genes [20]. A genomic scar score (combining loss-of-heterozygosity, telomeric allelic imbalance, and large-scale state transition metrics, as computed by tools such as scarHRD) was assessed for feasibility using the available copy-number segmentation data; the rationale for not computing this score is given in the Discussion.
Expression-augmented Cox model
To test whether gene expression improves prognostic power beyond the established genomic covariates, we fit elastic-net-penalized Cox regression models (glmnet, family="cox") [30] using the top-200 SHAP-ranked genes as candidate covariates. TMB, Aneuploidy Score, and (in a secondary cohort) BRCA1/2 status were forced into the model as unpenalized covariates (penalty.factor=0), while candidate genes were subject to elastic-net penalization and selection (penalty.factor=1). Two overlapping cohorts were analyzed: a primary cohort (n=235, all patients with RNA-seq data) using TMB and Aneuploidy Score as forced covariates, and a smaller cohort (n=163, patients with RNA-seq and BRCA1/2 status both available) additionally forcing in BRCA status. Model evaluation used nested cross-validation: an outer loop of 25 evaluations (5-fold × 5 repeats, stratified by event status) for unbiased performance estimation, with an inner grid search over the elastic-net mixing parameter α (0 to 1 in steps of 0.1) combined with glmnet's internal cross-validation for the regularization parameter λ, at each outer fold. Gene expression covariates were standardized using training-fold statistics only, applied to the corresponding held-out test fold. Performance was evaluated at both the λ value minimizing cross-validated deviance (λ.min) and the more conservative one-standard-error rule (λ.1se), using Harrell's concordance index (C-index). Because outer folds within a repeat are not independent, we additionally computed repeat-level (n=5) paired significance tests (paired t-test and Wilcoxon signed-rank test) comparing the augmented and baseline models.
Statistical software and availability
Analyses were performed in R (survival, glmnet, estimate packages) and Python (scikit-learn, shap). The complete analysis pipeline is available at https://github.com/AaronC-bioinfo/ovarian-cancer-platinum-response, archived at Zenodo (DOI: 10.5281/zenodo.20802753); a software description has been submitted to the Journal of Open Source Software.
Results
Feature-selection leakage substantially inflates reported classification performance, and is not specific to ovarian cancer
Unsupervised, leakage-free variance-based gene selection produced a mean AUC inflation of only +0.011 relative to the correct (train-only) implementation, consistent with a clean pipeline. In contrast, supervised F-score selection performed prior to train/test splitting inflated mean AUC by +0.223, reaching +0.552 for the support vector machine classifier at the 12-month threshold; 7 of 9 model-by-threshold combinations were significant at p<0.0001 across 30 repeated random splits. This magnitude of leakage-driven inflation, consistent with prior reports of feature-selection leakage in high-dimensional genomic data more broadly [13,14], is sufficient on its own to account for a large fraction of the gap between our leakage-free AUCs (Table 2) and the substantially higher AUCs (0.926–0.971) reported by comparable published classifiers on this same dataset [1].
Repeating the identical ablation pipeline in two additional TCGA cancer types confirmed this is not an ovarian-cancer-specific artifact (Table 1): both lung adenocarcinoma and colorectal cancer showed supervised-selection inflation of comparable or greater magnitude (+0.320 and +0.330, respectively), while unsupervised selection remained close to zero in both (+0.004 and +0.018). We interpret this as evidence of a systematic, field-wide methodological issue in cancer genomics machine learning rather than a limitation specific to the present dataset.

Overall-survival-threshold labels do not recover confirmed non-responders
The directly annotated clinical response variable, PRIMARY_THERAPY_OUTCOME_SUCCESS, was 89% missing within the platinum-treated cohort, leaving only 7 patients with a confirmed Progressive Disease annotation. Against this small but unambiguous ground truth, the overall-survival-threshold proxy label — the label used for all classification analyses in this and comparable studies — achieved 0/5 recall (95% CI: 0.000–0.522) on confirmed non-responders with adequate follow-up data. This indicates that OS-threshold labels predominantly capture overall mortality trajectory rather than drug-specific response, a distinct clinical construct, and that classifiers trained on this label should not be interpreted as models of platinum sensitivity per se.

A Cox proportional hazards model identifies aneuploidy as an independent, purity-robust survival predictor
In the complete-case cohort (n=432 patients, 242 death events), Aneuploidy Score was independently associated with overall survival (hazard ratio [HR] = 1.021, 95% CI 1.004–1.039, p=0.017), while log-transformed tumor mutational burden was not (HR=0.894, 95% CI 0.742–1.077, p=0.238), consistent with the generally low and relatively homogeneous TMB observed in HGSOC relative to more mutationally heterogeneous tumor types. The model achieved a concordance index of 0.570 (SE 0.021); the proportional hazards assumption held (Schoenfeld global p=0.178), and risk tertiles derived from the model separated significantly on Kaplan–Meier analysis (log-rank p=0.023; median OS 52.0, 51.9, and 39.4 months in the low-, medium-, and high-risk tertiles, respectively).
Because ribosomal/translation gene enrichment (below) is a recognized correlate of tumor cellularity, we tested whether this Cox model, and the biological signal driving feature importance, were confounded by tumor purity. ESTIMATE-derived tumor purity was not a significant Cox covariate when added to the model (HR=4.36, p=0.526) and did not materially change the concordance index (0.603 vs. 0.604 with purity added, n=235 RNA-seq-available subset), indicating the baseline survival model is not confounded by cellularity.
SHAP-based feature importance identifies a robust EMT/ECM signature; a co-occurring ribosomal signal is not robust
A fair, cross-validated comparison of three random forest feature-importance methods — MDI, permutation importance, and SHAP — found that MDI and SHAP converge closely (Spearman ρ = 0.98) once computed identically within cross-validation folds; permutation importance agreed more moderately with both (ρ ≈ 0.37–0.42), plausibly reflecting its known sensitivity to blocks of correlated features, which is characteristic of the co-expressed extracellular matrix / collagen gene set discussed below. SHAP was adopted as the primary reported importance method on this basis.
Pathway enrichment of the resulting gene rankings identified two consistent biological themes. An epithelial–mesenchymal transition (EMT) / extracellular matrix (ECM) signature (MSigDB Hallmark EMT, KEGG ECM-receptor interaction, KEGG Focal adhesion) was significant at every gene-list size tested (top 50 through top 500), under every importance method, and irrespective of whether the unstable 12-month threshold model was included in the cross-threshold average — the most robust finding in this study, and consistent with EMT's established role as a platinum-resistance mechanism in HGSOC [18,19]. Core genes CTNNB1 and THBS2 were robust anchors of this signature across all conditions tested; COL1A1 contributed strongly only when the unstable 12-month model was included, and FLNA did not rank as important under any method or condition tested (rank 299–508 across all methods and thresholds) despite prior inclusion in this pathway's cited gene set.
A second theme, ribosomal/translation gene enrichment (KEGG Ribosome and related Reactome/GO terms), was not robust under SHAP-based ranking at small gene-list sizes (not significant at the top 50 or top 100 genes) and only reached significance from a gene-list size of 200 onward (under the 12-month-inclusive SHAP ranking; without the 12-month threshold the ribosomal theme is already significant at the top 100 genes, adj p=0.020) [COWORK: confirm framing — state which 12-month condition the paper should present; see fixes/phase4_corrected_values.csv] — a marked change from the original MDI-based analysis, in which this theme was already significant at 100 genes. Purity-residualized re-analysis (above) also did not attenuate this signal; if anything, enrichment strength increased slightly after purity correction. We therefore regard the biological driver of the ribosomal signal as an open, unresolved question, for two independent reasons: it is not explained by tumor cellularity, and its statistical detectability under a less biased importance method is itself gene-list-size dependent. Plausible alternative explanations, not evaluated here, include tumor proliferation rate and RNA integrity.
BRCA1/2 mutation status improves survival prediction and provides a partial characterization of homologous recombination deficiency
Somatic BRCA1/2 mutations were identified in 33 of 409 patients with mutation data (8.1%). Adding BRCA1/2 mutation status to the Cox model (n=335 matched subset) yielded a significant, protective association (HR=0.455, p=0.024) and improved the concordance index from 0.573 to 0.588, consistent with the established clinical association between BRCA-related homologous recombination deficiency and platinum sensitivity. The top 500 variance-filtered genes showed no overlap with a curated panel of homologous-recombination-repair genes [20], which we interpret as expected rather than contradictory: unsupervised variance-based gene selection is structurally biased against stably expressed DNA-repair genes, such that HRD-related biology in this dataset is captured through mutation status rather than expression variance.
Gene expression does not improve prognostic power beyond established genomic and mutation covariates
Using rigorous nested cross-validation, elastic-net-augmented Cox models incorporating the top 200 SHAP-ranked genes showed no meaningful improvement over the genomic-only baseline in the primary, better-powered cohort (n=235; Table 3): concordance index improved from 0.585 to only 0.587 under the performance-maximizing regularization criterion (λ.min), and showed no improvement (0.585) under the more conservative one-standard-error criterion (λ.1se), which selected zero genes. In a smaller cohort additionally restricted to patients with BRCA1/2 status available (n=163), a modest improvement was observed under λ.min (0.557 → 0.606) but not under λ.1se (0.557 → 0.558). This λ.min result did not correspond to a sparse, interpretable gene signature — the selected elastic-net mixing parameter was α=0 (pure ridge regression) in the FINAL model fit on the full n=163 cohort, which distributed weight diffusely across all 200 candidate genes rather than selecting a specific subset; note, however, that α=0 was selected in only 8 of 25 outer cross-validation folds, so this is a property of the final model rather than a stable fold-level preference — and the elastic-net mixing parameter selected by inner cross-validation was unstable across outer folds, with no dominant value across the full 0–1 range tested. A repeat-level paired significance test (n=5 independent cross-validation repeats, accounting for non-independence among the 25 individual folds) gave a paired t-test p=0.036 but a Wilcoxon signed-rank p=0.063, the latter close to that test's resolution floor at this sample size. We interpret this λ.min result as a fragile, non-reproducible signal rather than a confirmed finding, and report the λ.1se result — a consistent absence of benefit from added gene expression, across both cohorts tested — as the primary result of this analysis.

Discussion
This study set out to determine how much confidence should be placed in machine learning predictions of platinum response derived from the TCGA-OV cohort, and what could still be learned reliably once known methodological pitfalls are addressed. Three independent lines of evidence — a controlled leakage ablation, a label construct-validity analysis, and cross-platform external validation — converge on a consistent picture: a meaningful fraction of the high accuracy reported in this literature for platinum-response classifiers is not attributable to genuine biological signal. We wish to be careful in how this conclusion is framed. Feature-selection leakage of the kind quantified here is a recognized, previously documented phenomenon in genomic machine learning generally [13,14], and is compounded by the broader observation that many gene-expression-derived signatures, entirely unrelated to the outcome of interest, are nonetheless found to be prognostically significant in cancer cohorts [15]. Our intent is not to single out specific prior studies as having erred, but to quantify the magnitude of this well-documented class of pitfall directly within the TCGA-OV platinum-response context, where it has not, to our knowledge, been previously measured.
It is also important to note that the stringency we apply here is appropriate specifically to studies that claim, implicitly or explicitly, a generalizable predictive model. A substantial fraction of genomic machine learning work on datasets of this kind is conducted with a descriptive or exploratory aim — characterizing associations, generating hypotheses, or interrogating a dataset's structure — for which the same leakage sensitivity does not carry the same interpretive risk. We would caution against over-generalizing our critique beyond the predictive-modeling use case it targets.
A further source of leakage not addressed in the present analysis, but worth noting explicitly, is that the TCGA RNA-seq data used throughout this study was processed as a single batch. Any batch effects introduced during sequencing or upstream bioinformatic processing are therefore present in the data prior to any train/test split, and are not detectable or correctable by the within-pipeline leakage controls implemented here. We regard this as a further limitation of TCGA-derived analyses generally, including our own, and a direction for future work incorporating batch-aware processing pipelines.
Regarding external validation, we consider the mechanistic finding — that RNA-seq and microarray platforms remain poorly correlated (r = −0.007) even after standard batch correction — to be the more informative and durable contribution of this analysis than the near-chance AUC figure alone. Framed this way, this result functions as a positive methodological finding (identifying why cross-platform validation fails in this setting) rather than solely a negative one (classifiers failing to generalize), and should inform the design of future cross-cohort validation studies in this space, which may require more sophisticated harmonization than standard ComBat correction, or validation exclusively within RNA-seq-profiled cohorts.
Turning to the biological findings that survived this more rigorous framework: the EMT/ECM signature identified here is, to our assessment, well supported. It is significant under every importance method, gene-list size, and 12-month-inclusion scenario tested, and is directly consistent with mechanistic evidence that EMT transcription factors (Snail, Slug) mediate cisplatin resistance in HGSOC cell lines [18], and with the broader literature on EMT as a chemoresistance mechanism [19]. In contrast, we regard the ribosomal/translation signal as a genuinely open question rather than a secondary confirmed finding: it is not explained by tumor cellularity, and it is not robust to gene-list size once a less biased importance method is used. We would discourage over-interpreting this signal in future work building on this dataset without further investigation into alternative explanations such as proliferation rate or RNA integrity.
The translational relevance of homologous recombination deficiency (HRD) to platinum and PARP-inhibitor therapy in HGSOC is well established [21]. Our HRD characterization here, however, has two compounding limitations, both of which likely cause us to underestimate the true HRD-positive fraction of this cohort. First, the public mutation annotation file used here reports somatic variants only; germline BRCA1/2 mutations, which contribute substantially to HRD in HGSOC, are excluded, so the true BRCA-mutant prevalence in this cohort is likely closer to the 15–20% reported in the literature than the 8.1% observed here. Second, we did not compute a genomic scar score (combining loss-of-heterozygosity, telomeric allelic imbalance, and large-scale state transitions), which would capture the substantial fraction of HRD-positive tumors that are BRCA-wildtype ("BRCAness"). This was not computable from the available data: the copy-number segmentation file in this cohort's public release reports total copy number only, and genomic scar algorithms require allele-specific segmentation that was not available without sourcing an alternative dataset, which we judged to be outside the scope of the present analysis. Our BRCA-mutation-based HRD covariate should therefore be read as a partial, lower-bound characterization of HRD status in this cohort; a full genomic scar score remains a direction for future work, contingent on sourcing allele-specific copy-number data.
Finally, contrary to our initial hypothesis, adding gene expression to the Cox model did not yield a robust, reproducible improvement in prognostic power beyond established genomic covariates. We regard this as a methodologically useful negative result rather than a failure of the analysis: naive, non-cross-validated feature selection at this stage could easily have produced an inflated concordance-index improvement resembling the leakage-driven inflation quantified in our classification analysis above, and only rigorous nested cross-validation with a conservative regularization criterion revealed that the apparent gain observed in the smaller BRCA-matched subset does not survive scrutiny. We report this modest, fragile signal transparently rather than suppressing or overstating it, consistent with the broader argument of this paper: that genomic machine learning claims in this literature should be evaluated under conservative, leakage-resistant criteria rather than the most favorable achievable result.
Limitations
This study has several limitations. All primary analyses derive from a single institution-aggregated dataset (TCGA-OV); the only independent validation attempted here (GSE63885) failed for platform-level reasons rather than providing a positive external replication, and access to an independent RNA-sequencing-based validation cohort (PTRC-HGSOC) was not available at the time of this analysis. The tumor-purity correction in this cohort is limited by a narrow observed purity range (0.587–0.808), which may understate the extent to which purity could confound expression-based analyses in a more heterogeneous cohort. The BRCA-augmented Cox model (n=335) is a non-random subset of the full cohort, within which the significance pattern of TMB and Aneuploidy Score covariates differs from the full n=432 model; this should be interpreted as a limitation of that specific matched-subset analysis rather than a contradiction of the primary Cox model. The Aneuploidy Score and BRCA covariates each show a borderline violation of the proportional hazards assumption in reduced-cohort subset analyses (Schoenfeld p=0.007 and p=0.042, respectively) despite holding in the full-cohort model, which we attribute to reduced sample size in these subsets rather than a substantive violation, but which should be disclosed. Finally, our BRCA-based HRD characterization is a partial, likely conservative estimate for the reasons discussed above.
Conclusion
Careful attention to feature-selection leakage, label construct validity, and cross-platform generalization substantially changes the picture of what TCGA-OV genomic data can currently support for platinum-response prediction in HGSOC. Under a leakage-free, label-honest framework, an EMT/ECM gene expression signature emerges as a robust correlate of survival risk across every analytical lens applied here, while genomic instability and BRCA1/2 mutation status — rather than gene expression — remain the most reliable prognostic covariates available in this dataset. We hope both the methodological framework and the validated biological signature presented here will be useful to future work in this area.
